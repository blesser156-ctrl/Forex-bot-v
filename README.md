# Forex Bot V1

Mobile-friendly forex trading dashboard.

Files:
- index.html
- style.css
- app.js

## GitHub Pages

Upload the three website files to the root of your repository.

Then go to:
Settings -> Pages -> Deploy from a branch -> main -> /(root)

## Important

This is a DEMO/UI version. It does not place real MT5 or broker orders.

For live execution, a secure server/VPS or MT5/broker API bridge is required. Never place broker passwords or API secrets in client-side JavaScript.
